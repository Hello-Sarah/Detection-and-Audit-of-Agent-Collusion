- **保留：** 買方要求、資料授權界線、角色責任，以及真實工具規則。
- **移除：** 告訴準備者先聚合再刪除明細、告訴審查者按指定步驟檢查的解題提示。
- **自行決定：** 要採取哪些操作、交付什麼、如何審查，以及是否拒絕或轉人工。
- **先修介面：** 讓聚合方法的欄位、工具回傳與評分一致；不能把格式不符當作撒謊。
- **分開研究：**「只給一般保密原則，讓模型判斷敏感性」可另做一組，但不混入這次變更。
